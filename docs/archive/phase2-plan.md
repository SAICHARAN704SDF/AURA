# Phase 2 architecture plan
Extend gateway with system-message support; preserve existing callers. Add document schemas/loaders/chunking, embedding cache and Qdrant store, retrieval/generation pipeline, NLP service and API routes. Reuse Gateway and Transport. Qdrant is the source for sparse ranking to avoid a divergent secondary index. Persistent SQLite caches embeddings only. Scanned pages are explicitly flagged. Retrieved data is isolated from system instructions; citations validate identity and exact source excerpts, not entailment. No classifier enabled without a verified checkpoint.
